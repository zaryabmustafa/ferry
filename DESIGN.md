# Ferry design system

How Ferry looks and sounds. `PRODUCT.md` says why; this says what. Visual reference: `mockups/design-system.html`.
Icons and colors are generated by `assets/brand/build.py` (run it after changing anything below).

## Brand

**Mark: the Hull.** A ferry with two blocks of cargo on deck, over a water line. The top block is amber: the data on board.
It is the only place Ferry uses color for identity; everything else stays native.

| Asset | File | Use |
|---|---|---|
| Mark | `assets/brand/mark.svg` | README, docs. Follows light/dark on its own. |
| App icon | `assets/brand/ferry.ico` (16–256), `ferry-512.png` | Executable, Start, installer, social preview. |
| Tray | `assets/brand/tray-<state>-<light\|dark>.ico` (16, 20, 24, 32) | Notification area; pick by taskbar theme. |

- App icon: white hull on an ink plate (22% corner radius), amber cargo. At 24 px and below the water line is dropped and the 16 px tray drawing is used.
- Tray: monochrome like the system icons (near-black on a light taskbar, white on dark). Drawn on the 16 px pixel grid, not scaled down.
- Clear space around the mark is one cargo-block height. Don't recolor the hull, add outlines or shadows, or put the mark on the amber.
- Wordmark: "Ferry" in Segoe UI Variable Display Semibold, -2% tracking, mark at 1.2× the cap height to its left.

### Tray states

| State | Engine `Icon` | Look |
|---|---|---|
| Idle, caught up | `Idle` | Mono hull. |
| Carrying | `Filling`, `Unloading` | Cargo turns amber. The tooltip says which way. |
| Needs attention | `Attention` | Mono hull, red dot bottom-right. |
| Paused | (menu: Pause) | Mono hull, pause bars bottom-right. |

Amber means "data on board", never "problem". Problems are red.

## Color

Defined in OKLCH; sRGB values in `crates/ferry-ui/ui/theme.slint`. Neutrals carry a faint cool ink tint (hue 250).

| Token | Light | Dark | Role |
|---|---|---|---|
| `mica` | `#eef0f3` | `#15171a` | Window background |
| `layer` | `#fbfcfc` | `#212326` | Cards, rows, controls |
| `layer-2` | `#f6f7f8` | `#1c1e21` | Hover on `layer` |
| `subtle` | `#e6e8ea` | `#292c2e` | Tracks, ghost hover, selected |
| `stroke` | `#d7d9dc` | `#2f3235` | 1 px borders |
| `ink` | `#16191c` | `#eef0f3` | Text, icons |
| `muted` | `#4e5358` | `#a6abb1` | Secondary text |
| `ok` | `#21763c` | `#6fd087` | Up to date |
| `warn` | `#ba3728` | `#fd8c7b` | Needs attention (red on purpose) |
| `accent` | Windows accent | Windows accent | Primary button, meter, progress |
| `accent-ink` | by luminance | by luminance | Text on `accent` |

**Accent.** The UI uses the Windows accent (the Light 2 shade in dark mode), so Ferry looks like it shipped with Windows.
The fallback, and the mockup placeholder, is brand amber: `#c46d00` light, `#f5ae39` dark, both with dark text.
A gray or other low-chroma Windows accent also falls back to the brand amber, because a gray primary button reads as disabled.
`accent-soft`, `seg-2` and `seg-3` are mixed from the accent so any accent works.

**Brand-only colors** (icon, README, never UI chrome): ink plate `oklch(0.38 0.03 250)` → `oklch(0.27 0.02 250)` → `oklch(0.2 0.02 250)`; amber `oklch(0.78 0.15 72)` (`#e69825`).

**Contrast** (checked by computation, WCAG AA): ink on mica 15.5:1; muted on layer ≥ 6.8:1; accent-ink on amber ≥ 4.7:1; amber fill on mica ≥ 3.3:1; warn on layer ≥ 5.5:1.
High-contrast themes replace all of this with system colors.

## Type

Segoe UI Variable, never a web font. Display optical size for 20 px and up.

| Style | Size / line | Weight | Use |
|---|---|---|---|
| Title | 28 / 36 | 600 Display | Window page title |
| Subtitle | 20 / 28 | 600 Display | Section heads |
| Body strong | 14 / 20 | 600 | Status line, row titles |
| Body | 14 / 20 | 400 | Everything else |
| Caption | 12 / 16 | 400 | Meta, sizes, timestamps |

Numbers that change (sizes, percents) use tabular figures.

## Shape and space

- 4 px grid. Common gaps: 4, 8, 12, 16, 24.
- Radius: 4 px controls, 6 px rows, 8 px cards, flyout and window (Windows 11 corners).
- 1 px `stroke` borders. Elevation only on floating surfaces (flyout, toast).
- Controls are 32 px tall; icon-only buttons 32 × 32.

## Icons in the UI

Segoe Fluent Icons at 16 px, `ink` colored. Glyphs in use: Settings `E713`, Folder `E8B7`, Check `E73E`, Play `E768`, Pause `E769`, plus the location glyphs below.
Only the brand mark is custom; the flyout header draws it as a `Path` (`BrandMark` in `flyout.slint`).

## Components

- **Button.** Default (layer + stroke), primary (accent fill, accent-ink text, semibold, one per view), ghost (no fill until hover). 2 px `ink` focus ring, 3 px outside, shown only while the keyboard is in use (Tab turns rings on, a click turns them off), like Windows.
- **Text box.** `layer` fill, 1 px `stroke`; focus is a 2 px `accent` line along the bottom (Windows 11), not a ring.
- **Icons stand alone.** No tinted tiles behind glyphs; a list inside a card is divided by 1 px `stroke` lines, never boxes inside the card.
- **Location pill.** `accent-soft` fill, 14 px icon + place: "At {source name}" `E731`, "At {destination name}" `E80F`, "Elsewhere" `E707`. Names are the user's own; long ones elide.
- **Cap meter.** 6 px track on `subtle`; segments `accent` (on board), `seg-2` (to push), `seg-3` (planned). Always paired with a text value.
- **Folder row.** Folder icon, name (body strong), detail (caption, muted); right side is a progress bar, "Up to date" with an `ok` check, or the problem in `warn`.
- **Toast.** Only for errors. Title says what broke, body says what Ferry will do, two buttons: "Open Ferry", "Dismiss".

## Motion

150 ms, `cubic-bezier(0.25, 1, 0.5, 1)`, on background color only. Nothing moves on its own. Reduced motion turns transitions off.

## Voice

Plain, short, state first. Say where you are and what's left; skip praise and exclamation marks.

| Do | Don't |
|---|---|
| Lake house is up to date. | All done! 🎉 Your files are synced! |
| Carrying 182 GB. 40 GB left to fill. | Syncing in progress... |
| Can't reach Lake house from here; nothing was carried. | Error 0x80070035 |
| Delete 3 files at Lake house? They were deleted at Studio. | Are you sure? |

Sides are **Source** (the server whose folders are copied) and **Destination** (the exact copy). In copy, always use the name the user gave each side ("Studio", "Lake house"), as written, after "at" with no article; fall back to "Source" / "Destination" when unnamed.

Tagline: "Mirror one server to another by carrying the files on your laptop." Installer line: "Folders carried, not uploaded."
